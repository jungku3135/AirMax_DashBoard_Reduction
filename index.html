점검 구분
1. 매트
순번 1~5 — 볼 / 매트 / 스프링 / 흡입 / 호스 상태 점검
① 볼 상태 점검 (육안)
볼이 빠진 곳이 있는지, 파손된 볼이 있는지 확인
② 매트 상태 점검 (육안)
외관 심한 오염, 찌그러짐, 매트 깨짐·파손 여부 확인
③ 스프링 상태 점검 (매트 전체를 밟아보며 확인)
밟았을 때 볼이 정상적으로 복구되는지 확인
④ 흡입 상태 점검 (청취)
밸브에서 흡입하는 소리가 정상적으로 들리는지 확인
⑤ 호스 상태 점검 (육안 및 청취)
집진기 연결부까지 끊어진 곳이 있는지, 바람 새는 소리가 있는지, 브라켓에서 빠지지 않았는지 확인
2. 집진기
전원/동작 / 센서 / 표시상태(LED·LCD 중 선택) / 모뎀 통신 상태 점검
① 전원 및 동작상태 (육안)
전원이 켜져 있는지, 흡입이 정상 동작하는지 확인
② 센서 상태 (육안 및 시연 — 센서 통과)
센서 앞을 지나가거나 근접했을 때 정상적으로 감지하여 동작하는지 확인
표시 방식 선택
점검 중인 제품이 LED 표시 제품인지 LCD 표시 제품인지 선택하면, 해당하는 점검 항목만 아래에 표시됩니다.
③ LED 표시상태 (육안)
상판 LED가 상태(동작, 대기 등)에 따라 정상적으로 점멸되는지 확인
③ LCD 표시상태 (육안)
제품 ID, 소모품 사용량, 동작시간, 동작횟수, 센서, 모터 상태가 모두 정상 표기되는지 확인하고, 흡입 동작 시간에 따라 값이 변화하는지 확인
④ LCD 모뎀 통신상태 (점검 대시보드 확인)
통신이 정상적으로 연결되는지, 공기질 센서 농도가 정상 표기되는지 확인
통신상태
공기질 센서 상태
3. 소모품
사용률은 교체 여부와 상관없이 현재 시점 확인용으로 기록하면 됩니다. 포집량 측정은 실제 교체를 진행했을 때만 아래 버튼을 눌러 입력해주세요.
① 소모품 사용률 기록
교체 여부와 무관하게, 현재 시점의 소모품 사용률(%)을 확인하여 기록 — 기준치가 아닌 기록 목적
② 먼지봉투 포집량 측정 (교체 진행 시, 저울 측정)
먼지봉투 교체 시 포집된 먼지 무게(g)를 측정하고, 반드시 집진기에 포집량을 입력
